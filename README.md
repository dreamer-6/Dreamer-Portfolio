# Dreamer Portfolio

A responsive personal portfolio website for presenting my work, skills, and contact information.

## Preview

Open `index.html` in any modern web browser to view the site locally.

## Features

- Hero and introduction section
- About, skills, and project showcases
- Responsive navigation and layout
- Contact and social links

## Built with

- HTML5
- CSS3
- JavaScript

## Getting started

1. Clone or download this repository.
2. Open the `Dreamer-Portfolio` folder.
3. Launch `index.html` in a browser.

No installation or build step is required.

## Site Links:
https://dreamer-6.github.io/Dreamer-Portfolio/

## Project structure

```text
Dreamer-Portfolio/
├── index.html      # Main page markup
├── style.css       # Site styling
└── README.md       # Project documentation
```

## Customization

Update the text, project links, images, social links, and colors in `index.html` and `style.css` to make the portfolio your own.
